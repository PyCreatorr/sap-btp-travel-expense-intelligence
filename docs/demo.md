## Scope of the demonstration

The travel reference layer is based on locally stored SAP DMO sample data, with
enriched airport coordinates. Deterministic validation checks extracted fields and
totals; Travel Data Matching is a separate reference-data comparison. Cost Assessment
benchmarks against the available catalog, not a live or historical airfare-availability feed.
The posting proposal is a draft and does not execute an ERP posting.
